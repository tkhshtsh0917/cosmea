# Provenance

Cosmea originated from a user-supplied prototype named st-logq. It was reviewed and reorganized in November 2026. The prototype did not specify a project license; no open-source distribution license has been assigned to this development checkout.

The implementation draws on the papers listed in the README. Reference code from NonameUntitled/logq was inspected but is not bundled into the package. Sentence Transformers, PyTorch and NumPy are installed as dependencies, under their respective licenses. Upstream copyright and license notices must be preserved when distributing their material.
